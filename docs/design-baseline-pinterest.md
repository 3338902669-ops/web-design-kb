# Design Baseline — Pinterest.design 视觉学习版（2026-09-03，视觉模型逐段学习）

> 用户指令：用视觉学习模型认真学 https://pinterest.design/，以后外国客户设计尽量靠拢。
> 方法：抓站 → 分段截图（1440×900×6 段）→ 工作密钥官方视觉模型逐段结构化观察（5/6 段成功，证据存 workspace\pinterest-design-study\visual-study.json + seg-*.png）。

## 视觉模型逐段观察（原文摘录）
- 首屏：顶导航 + 中央主视觉 + 超大白色标题；深色遮罩压暗 + 白字醒目；标题与图间留白充足；不规则拼贴非严格等宽网格；悬停显示按钮。
- 文章头图区：**5 列等宽图片网格 + 右侧留白列**；标题 ~40px > 作者 16px > 描述 14px > 辅助 12px；白底深灰黑字 + 黑色按钮点缀；图片大间距、正文间距疏朗。
- 三卡片区：三列等宽卡片网格；白底黑字 + 橙红/浅黄绿极小点缀；圆角图片 + 彩色小标签叠加；轮播点/箭头/按钮；专业友好品牌风。
- 文章列表：三列等宽卡片；**图上方 + 标题下方（最大）+ 作者灰小字、无正文**；圆角图片、实拍与插画混合；间距均匀、底部留白多。
- 尾部：三卡横排 + Load more 按钮 + **黑色页脚**；标题中粗、作者灰、按钮次大；社媒调性、设计感强。

## 修正后的风格十律（v2，覆盖 v1）
1. **白底为主**：正文区纯白/浅灰 #F7F7F7；深色只两处——首屏 hero（深底大图或深色块 + 白色超大斜体标题）与页脚（黑底白字）。
2. **点缀色极克制**：橙红 #E60023 只给 ❤、CTA、hover、小标签，面积 <5%；图片自身色彩是页面主要色彩来源。
3. **标题层级**：hero 斜体白字 96px 级仅一句；页面标题 40px 中粗；卡片标题 18px 黑粗；作者/辅助 12-14px 灰 #767676；无第三种强调色。
4. **卡片公式**：圆角 **8px**、无边框、无阴影（hover 才有轻微抬升）；图在上、标题在下（图上叠字只用于 hero 和首屏拼贴）。
5. **网格**：正文三列等宽卡片；首屏可用不规则拼贴；右侧留白列是可选项。
6. **留白**：区块间距 96-160px、卡片间距 24-32px、底部留白大于顶部；分区靠留白而非线框。
7. **动效极轻**：hover 图片缩放 ≤1.03/300ms、卡片抬升 -4px、轮播点、渐显 ≤400ms；禁止粒子/WebGL/重滚动叙事。
8. **语气**：专业友好、社媒调性（不是奢侈高冷、不是科技硬核）；标题为短句。
9. **字体（本地等价）**：标题 Segoe UI/-apple-system 斜体或 500 字重；正文同栈 16px；靠字号与字重做层级。
10. **可访问**：390px 单列大图卡；灰字不浅于 #767676；reduced-motion 全静态；对比达标。

## 反模式（禁）
整页暗黑霓虹 / 满屏粒子 / 多色渐变 / 花边框 / 卡片大阴影 / 重 GSAP 叙事 / 图片上叠满字。
