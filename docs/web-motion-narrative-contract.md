## 与本流程的对应（执行顺序）
1. 【客户分析后】填写 0-2 节（主题/交互/幕结构），才能开始选材。
2. 【查 motion-db 时】3 节逐幕填：候选条目名/来源 + 语义匹配理由 + 意图声明；候选仍走 呈现用户确认。
3. 【用户确认后】复制完整 prompt / 组件 url 作基底，并写 3.1 适配改写指令（品牌色/真实文案/内容锚点/节奏），禁止直出照搬。
4. 【实现时】按 4-5 节定义转场语言与 master timeline（GSAP 全局滚动叙事）。
5. 【验收时】按 6 节意图表逐块核对 + 常规门禁（桌面/390/reduced/console/像素 + codex-security）。

## 4. 转场与连续运动语言（丝滑的根本）
- 共享锚点（全页贯穿元素，至少 1）：贯穿整页持续运动的单一系统（同一条光带 / 同一粒子场 / 同一进度信号），是幕间连续感的来源。名称与实现：
- 统一运动语言：缓动（默认 power3.out）+ 时长基准（入场≤500ms / 幕≤800ms）+ 方向一致（例如一律自下而上，勿混入左右乱飞）。
- 幕间衔接方式（逐对 Mx到My）：□共享锚点连续（锚元素下幕继续运动/换色） □共享元素 morph（上幕物件变形为下幕物件） □节奏桥（上幕尾声放慢+下幕入场承接）。写明每对方式与对象。
- 禁止：无共享元素的硬切、每幕换一套视觉语言、动效与滚动进度脱节。

## 填写示例（节选：婚礼/派对高端视觉页）
- 0 核心隐喻：把仪式做成光影 → 全页共享一条光贯穿（顶光带→首屏光束→作品卡辉光→CTA 聚光）。
- 2 M0 首屏=吸引（强词+一句+CTA）；M1 服务=展开仪式/派对/品牌三段，统一上浮+共享光点尾迹承接。
- 3 M0 候选 Agent Wave/3D Future Flora… 语义=光粒子流动贴合隐喻。
- 4 转场：幕间全用共享锚点光带连续；入场统一 400ms power3.out 自下而上。
- 5 master：ScrollTrigger 驱动总进度，光带亮度=master 进度，各块在 40%/70%/100% 处挂接。
- 6 验收：每块有意图、有共享元素、reduced 下静态仍讲完主链。
